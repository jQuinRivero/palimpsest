# palimpsest backend

The FastAPI service for
[palimpsest](https://github.com/jQuinRivero/palimpsest), a typography-first
collation reader for comparing two versions of a literary text.

The service provides document ingestion, text normalization, passage
alignment, word-level diffing, expiring comparison storage, and TEI P5 export.
It is distributed as part of the full palimpsest source repository rather than
as a standalone end-user application.

For installation, usage, documentation, and community information, see the
[project README](https://github.com/jQuinRivero/palimpsest#readme).
