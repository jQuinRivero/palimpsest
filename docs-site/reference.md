# Specification reference

The top-level `docs/` directory is the normative specification for implementers. It stays in place and is not duplicated into this guide.

Use this site when you want to run palimpsest, read a comparison, understand the architecture at a high level, or decide where to start. Use `docs/` when you need exact contracts, invariants, edge-case policy, test expectations, or the accepted decision records.
